
# Employee Management Application

A full-stack Employee Management application developed using **React, Spring Boot, and MySQL**.

The application is containerized using **Docker** and **Docker Compose**. **Jenkins** is used to automate the CI/CD pipeline, while **Docker Hub** is used for storing Docker images.

The application is deployed on **AWS EC2**, and **Terraform** is used for infrastructure provisioning. Kubernetes manifests are also included for container orchestration.

### DevOps Flow

**GitHub → Jenkins → Docker → Docker Hub → AWS EC2 → Application**
