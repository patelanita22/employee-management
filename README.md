# Employee Management Application

 


 


 


A containerized Employee Management application deployed using Docker, Docker Compose, Jenkins CI/CD, DockerHub, and AWS EC2.

## Project Overview

This project is a full-stack Employee Management application consisting of:

- Frontend application
- Backend REST API
- MySQL database

The application is containerized using Docker and deployed on an AWS EC2 instance using Docker Compose.

Jenkins is used to automate the CI/CD pipeline.

## Technologies Used

### Application

- Frontend: React
- Backend: Java Spring Boot
- Database: MySQL

### DevOps
- Git
- GitHub
- Docker
- Docker Compose
- Jenkins
- DockerHub
- AWS EC2
- Linux
- Bash/Shell Scripting
